# Запуск на своём компьютере (бесплатно)

Бот работает, пока компьютер включён и не спит. Если компьютер выключен,
Telegram хранит сообщения до 24 часов, и после запуска бот их обработает.
Сводки, время которых пришлось на выключенный компьютер, не приходят.

## 1. Установите Python (один раз)

- **Windows:** скачайте Python 3.12 или новее с <https://www.python.org/downloads/>.
  В установщике **обязательно отметьте «Add python.exe to PATH»**.
- **macOS:** скачайте установщик с того же сайта или выполните `brew install python`.

## 2. Скачайте код бота

Вариант A, без git: откройте
<https://github.com/usershoislom/onecargobot/tree/claude/keen-gates-9jcuyd>
→ зелёная кнопка **Code** → **Download ZIP** → распакуйте, например, в `Documents\onecargobot`.

Вариант B, с git:
```
git clone -b claude/keen-gates-9jcuyd https://github.com/usershoislom/onecargobot.git
```

## 3. Положите ключи в папку бота

1. **`service_account.json`**: JSON-ключ сервисного аккаунта Google. Переименуйте
   его ровно так и положите рядом с `start.bat`.
2. **`.env`**: при первом запуске `start.bat` (или `./start.sh`) создаст его из
   шаблона и откроет в Блокноте. Заполните:
   ```
   TELEGRAM_BOT_TOKEN=токен от @BotFather
   ADMIN_USER_IDS=1024185305
   SPREADSHEET_ID=1U5oTuWtv29_U81h-UF1bghu9l_S4gkofaYGZ6SHFFRQ
   GEMINI_API_KEY=ключ Gemini
   GROQ_API_KEY=ключ Groq
   ```
   Остальные строки можно не менять. Сохраните файл.

Таблица должна быть открыта для email сервисного аккаунта с правами **Editor**
(Share → вставить `client_email` из JSON).

## 4. Запуск

- **Windows:** двойной клик по **`start.bat`**. Откроется чёрное окно, в нём
  должна появиться строка `Bot ready`. **Не закрывайте окно**: закрыли окно —
  бот остановился.
- **macOS:** в Терминале: `cd ~/Documents/onecargobot && ./start.sh`. Пока
  работает скрипт, Mac не уходит в сон.

Первый запуск занимает 1–3 минуты: устанавливаются библиотеки. Если бот упадёт,
скрипт сам перезапустит его через 10 секунд.

Проверка: напишите боту `/whoami`. Ответ должен быть «Role: admin». При первом
запуске бот сам создаст в таблице вкладки Log, Today и Settings.

## 5. Чтобы компьютер не засыпал

- **Windows:** Параметры → Система → Питание → «Переводить в спящий режим»:
  **Никогда** (при питании от сети).
- **macOS:** `start.sh` сам не даёт Mac уснуть. Но если закрыть крышку ноутбука,
  он всё равно уснёт.

## 6. Автозапуск при включении компьютера (по желанию)

- **Windows:** нажмите Win+R → введите `shell:startup` → Enter. В открывшуюся
  папку перетащите **ярлык** на `start.bat` (правой кнопкой → «Создать ярлык»).
- **macOS:** скопируйте `start.sh` в `start.command` (`cp start.sh start.command`),
  затем Системные настройки → Основные → Объекты входа → «+» → выберите `start.command`.

## 7. Запасной OCR (по желанию)

Нужен только когда Gemini недоступен, чтобы запасной ИИ мог читать PDF и фото.
- **Windows:** установщик Tesseract: <https://github.com/UB-Mannheim/tesseract/wiki>.
  При установке отметьте добавление в PATH.
- **macOS:** `brew install tesseract`

Без Tesseract бот работает, просто в запасном режиме хуже читает сканы.

## Важно

- **Запускайте только одну копию бота.** Две копии с одним токеном конфликтуют
  (в логе ошибка `Conflict: terminated by other getUpdates request`).
- **Обновление:** скачайте новый ZIP (или выполните `git pull`) и перезапустите.
  `.env` и `service_account.json` не трогайте: в репозитории их нет.
- `.env` и `service_account.json` никому не отправляйте.
